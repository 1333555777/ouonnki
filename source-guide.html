如何把自有版权视频接入 OuonnkiTV

只接你自己有权利分发的视频（已购、自制、公版/CC、已授权）。三步：托管文件 → 写片源 JSON → 站点设置里填地址。

总览 ① 托管文件 ② 写 JSON ③ 接进设置 常见坑

总览

你的视频文件mp4 / m3u8 等
→
托管处支持 Range + CORS
→
片源 JSON描述文件
→
站点设置填 JSON 地址
→
播放三端可用

视频能不能拖进度条、能不能跨域播放，取决于托管处，与播放器无关。下面每步都给可直接复制的命令。

① 把视频文件放到能直链的地方

浏览器直接拉视频，托管处必须同时满足两点：

要求为什么怎么满足
支持 Range 请求拖动进度条必需，否则只能从头播对象存储 / CDN / 正规服务器都支持。家庭宽带直接暴露不行（无公网 IP、运营商封 80/443）
允许 CORS 跨域片源域名 ≠ 站点域名时会拦截托管处加响应头 Access-Control-Allow-Origin: *；懒得配就走第③步的「代理前缀」兜底

三种托管（按省事程度）

对象存储

阿里云 OSS / 腾讯云 COS / Cloudflare R2。原生支持 Range，控制台可一键开 CORS。最省心。

自有 NAS / 服务器

nginx 开目录 + 加 CORS 头即可。需有公网可达地址。

网盘直链

能拿到稳定直链（直接返回视频字节）才行，临时链接会失效。

大文件（>1–2GB）建议切成 HLS

单文件 MP4 只要支持 Range 也能播；但大文件切片成 .m3u8 后加载更快、自适应码率。本地装好 ffmpeg 后一条命令：

ffmpeg -i 电影.mp4 -c:v h264 -c:a aac -hls_time 10 -hls_list_size 0 -f hls index.m3u8
# 产出 index.m3u8 + 一堆 .ts，一起上传；片源里 vod_play_from 填 m3u8

② 写一份片源 JSON

每个视频一个条目。用到的字段：

字段含义
vod_name标题
vod_pic海报图地址（可空）
vod_content简介（可空）
type_name分类：电影 / 剧集 / 纪录片…
vod_play_from线路/清晰度名。多组用 $$$ 分隔；m3u8 填 m3u8
vod_play_url播放地址。集与集用 # 分隔，单集写 集名$地址
分隔符速记：一份文件里 组 用 $$$ 隔、集 用 # 隔、集名和地址 用 $ 隔。

可直接复制的模板（把地址换成你自己的）：

{
  "code": 1,
  "msg": "我的版权内容",
  "page": 1, "pagecount": 1, "limit": 50, "total": 3,
  "list": [
    {
      "vod_id": "1",
      "vod_name": "我的电影（完整版）",
      "type_name": "电影",
      "vod_year": "2024",
      "vod_remarks": "已授权",
      "vod_pic": "https://你的图床.com/poster.jpg",
      "vod_play_from": "default",
      "vod_play_url": "正片$https://你的视频域名.com/电影.mp4",
      "vod_content": "简介"
    },
    {
      "vod_id": "2",
      "vod_name": "我的剧集",
      "type_name": "剧集",
      "vod_year": "2024",
      "vod_remarks": "多集",
      "vod_pic": "",
      "vod_play_from": "default",
      "vod_play_url": "第1集$https://你的视频域名.com/e1.mp4#第2集$https://你的视频域名.com/e2.mp4",
      "vod_content": "多集用 # 分隔"
    },
    {
      "vod_id": "3",

不想手敲？用扫描脚本

本地有一堆视频文件时，用仓库里的脚本一键生成（标题/分类从文件名自动推断，多集自动合并）：

python build/make_source_from_folder.py \
  --dir "D:/影片" \
  --prefix "https://cdn.example.com/movies/" \
  --out site/my-source.json \
  --cat 电影 --year 2024

③ 在站点设置里接上

  1. 打开 OuonnkiTV → 右上角「设置」
  2. 视频源区域点「+ 添加片源」
  3. 名称随意；URL 填第②步那个 .json 的完整地址（以 .json 结尾，页面会当静态文件直读，不再拼接口路径）
  4. 点该行右侧「自检」，应显示「返回 N 条，含播放地址 N 条」
  5. 保存 → 回片库搜索/浏览即可播放
若播放器报跨域（CORS），在设置里填「代理前缀」兜底（就是配套做的那个 Worker / Python 代理）： 
# Cloudflare Worker 版（推荐）
https://你的worker子域.workers.dev/?url=

# 本地 Python 代理版
http://127.0.0.1:8787/?url=
# 注意结尾的 ?url= 必须带，漏了拼出来就是 404

常见坑

  • 片源地址必须是视频直链（直接返回视频字节），不是网页。自检「返回了但没播放地址」通常是把网页链接当成了视频地址。
  • 静态 JSON 没有服务端搜索：搜什么都会返回全部，这是性质不是 bug。想按关键词筛就接苹果 CMS 接口（填接口根地址，不带 .json，页面自动拼 /api.php/provide/vod/?ac=videolist&wd=）。
  • 地址里的空格、中文会被自动转义成 %20 / %xx，正常，不用手改。
  • 对象存储默认可能不开 CORS，控制台搜「跨域」加一条 Access-Control-Allow-Origin: * 即可。
