片源生成器

从 Internet Archive 的公有领域 / 知识共享影视库直接生成片源 JSON。 整个跑在你的浏览器里：请求由你的浏览器发出，生成的 JSON 也只下载到你本机，不经过任何第三方服务器。

怎么用生成的 JSON

  1. 点「下载 JSON」，把文件命名成 source-demo.json。
  2. 用它替换站点目录里的同名文件（就是你现在访问地址下的 /source-demo.json），重新上传到 Cloudflare 即可。
  3. 也可以在片源设置里把它当成一个新源：把文件传到任意静态空间， 地址填 https://你的域名/xxx.json，然后「自检」。

定时自动重抓（三种做法）

① GitHub Actions（推荐，抓完自动更新站点）

把生成器脚本放进仓库，用定时任务每天跑一次，抓完自动提交。若你的站点也是从该仓库部署的 （Cloudflare Pages / GitHub Pages），提交即生效，全自动。 

# .github/workflows/archive-refresh.yml
name: 定时重抓片源
on:
  schedule:
    - cron: "17 3 * * *"   # 每天 UTC 03:17（北京时间 11:17）
  workflow_dispatch:        # 也支持手动点一下
jobs:
  refresh:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.11"
      - name: 生成片源
        run: python build/build_archive_source.py --collection feature_films --limit 24
      - name: 有变化就提交
        run: |
          git config user.name "bot"
          git config user.email "bot@example.com"
          git add site/source-demo.json site/archive-source.json
          git diff --quiet --cached || git commit -m "chore: 自动重抓片源"
          git push

② Windows 任务计划程序

管理员身份打开 PowerShell，执行一次即创建每天 11:00 自动运行的任务：

$act = New-ScheduledTaskAction -Execute "python" `
  -Argument "C:\path\to\build\build_archive_source.py --collection feature_films --limit 24" `
  -WorkingDirectory "C:\path\to"
$trg = New-ScheduledTaskTrigger -Daily -At 11:00
Register-ScheduledTask -TaskName "OuonnkiTV-片源重抓" -Action $act -Trigger $trg -Description "每天重抓 Internet Archive 公有领域片源"

③ Linux / macOS cron

# 每天 11:00 重抓，日志写到 refresh.log
0 11 * * * cd /path/to/project && /usr/bin/python3 build/build_archive_source.py --collection feature_films --limit 24 >> refresh.log 2>&1
提醒：重抓会按下载量重新排序，结果列表可能整体变化；脚本会自动跳过抓取失败的条目， 并过滤掉成人 / 剥削片关键词。想固定风格就指定关键词，例如 --query "title:(chaplin)" 只抓卓别林相关。

命令行用法

python build/build_archive_source.py                       # 默认抓 24 条
python build/build_archive_source.py --collection silent_films --limit 12
python build/build_archive_source.py --query 'title:(chaplin)' --limit 10
python build/build_archive_source.py --no-verify            # 跳过实测，速度快很多
数据来源 Internet Archive · 仅收录公有领域 / CC 授权内容 · 生成过程全部在本地浏览器完成
