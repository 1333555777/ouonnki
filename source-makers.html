公开版权源生成器

把 NASA / Wikimedia / Pexels / Pixabay 的公开授权视频，一键生成 OuonnkiTV 可用的苹果 CMS 格式 JSON 片源。

NASA 资源主机与 Wikimedia API 没有开放浏览器跨域（CORS），在网页里直连会被拦，需走你的跨域代理（结尾带 ?url=）。 已在站点设置里配过代理的，把同一个前缀粘到这里即可。
Pixabay 已开放 CORS，可留空直连；Pexels 因 CORS + 鉴权限制，浏览器内无法生成，请改用 build_pexels_source.py 脚本。

🚀 NASA 影像（美国联邦政府作品 · 公有领域）

无需 key，直链 mp4。搜索多个航天/自然主题，解析出 mp4 + 海报。


  


  
  

    
📚 Wikimedia Commons 视频（CC / 公有领域）

    
无需 key，直链 webm/ogv（Chromium 可播，Safari 对 webm 支持有限）。必须填代理前缀。

    

      
      
      
      
      
    

    

    

  


  
  

    
🎬 Pexels 免费素材（免费可商用）

    
需免费 key（申请）。因 CORS + 鉴权，浏览器内生成受限，推荐用脚本 build_pexels_source.py --key 你的KEY；下方按钮会尝试（需能转发 Authorization 头的代理），失败请改用脚本。

    

      
      
      
      
      
    

    

    

  


  
  

    
🌅 Pixabay 免费素材（免费可商用）

    
需免费 key（申请）。已开放 CORS，可直连（代理留空即可）。

    

      
      
      
      
      
      
      
    

    

    

  


  

    
📦 生成后怎么用

    

      1. 点「下载」把 json 存到本地；

      2. 上传/覆盖到你的站点根目录（与 index.html 同级），文件名保持 nasa-source.json 等；

      3. 在站点「片源设置」里点对应的一键预设（NASA 影像 / Wikimedia 视频 / Pexels 素材 / Pixabay 素材），保存即可。

      4. Pixabay 默认源是空的，必须先生成并覆盖 pixabay-source.json 才有内容。
