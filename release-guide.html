一、发布到 GitHub Releases

  1. 打开仓库的 Releases 页面
    进入 github.com/1333555777/OuonnkiTV/releases，点右上角绿色按钮。
    github.com/1333555777/OuonnkiTV/releases
    Code  Issues  Pull requests  Actions  Projects  Wiki
    Releases  0   → 点击 Create a new release
  2. 填标签与标题
    Choose a tag 填 v2.0.0（页面里的下载链接就是按这个版本号拼的，一定要一致）， Release title 建议写 OuonnkiTV v2.0.0。
    最常填错的地方：tag 必须是 v2.0.0（带 v 开头）。写成 2.0.0 会让 releases/latest/download/… 这类链接全部 404。
  3. 拖入三个安装包
    把下面三个文件拖到 “Attach binaries by dropping them here or selecting them” 区域， 文件名不要改： 
    OuonnkiTV-TV-arm64-v2.0.0.apk
OuonnkiTV-Android-v2.0.0.apk
OuonnkiTV-2.0.0-win-x64-portable.zip
    Windows 那个包 121 MB，GitHub 单个文件上限 2 GB，没问题；但上传时间取决于你的网络，别中途关页面。
  4. 发布
    点 Publish release。发布后这些地址就生效了：

    站点现在用的是本地直链，永远可用。如果想让主按钮走 GitHub，把 index.html 里的 LOCAL_DL 换成 RELEASE_BASE + "/" 即可。

二、Android 安装（电视 / 手机）

  1. 把 APK 传到设备（U 盘、微信文件传输、或用电视上的浏览器直接打开下载页）。
  2. 点击安装，系统会提示「未知来源应用」→ 允许。部分电视需要在 设置 → 设备偏好设置 → 安全和限制 → 未知来源 里先给文件管理器授权。
  3. 装好后打开，默认加载站点首页。想换成自己的实例： 按遥控器菜单键 / 手机右上角菜单 → 设置首页地址，填入后保存。
电视端包名 com.ouonnki.tv，手机端 com.ouonnki.tv.mobile， 两个可以同时装在一台设备上，互不影响。

三、Windows 安装

  1. 下载 OuonnkiTV-2.0.0-win-x64-portable.zip，解压到任意文件夹（建议不要放 C 盘根目录）。
  2. 双击 OuonnkiTV.exe 即可运行，无需安装。
  3. 若弹出 Windows SmartScreen 蓝色提示，点 更多信息 → 仍要运行。
  4. 换地址：帮助 → 打开配置文件夹 → 编辑 config.json 里的 homeUrl，重启生效。

四、macOS 安装（装成独立 App）

  1. 用 Chrome 或 Edge 打开站点，点地址栏右侧的「安装」图标（或菜单 → 投放、保存和共享 → 安装此站点为应用）。
  2. 或用 Safari 打开 → 分享 → 添加到程序坞，同样得到独立窗口的 App。
  3. 之后从 Launchpad / 程序坞打开，就是一个独立窗口的客户端，不显示浏览器标签页。

五、iOS / iPadOS 安装（添加到主屏）

  1. 用 Safari 打开站点（必须是 Safari，Chrome 不支持添加主屏）。
  2. 点底部「分享」按钮 → 往下滑，选 添加到主屏幕。
  3. 确认名称后点「添加」，桌面就出现图标，打开即全屏运行，和原生 App 无异。

六、手动上传到 Cloudflare Pages

可以手动传，不用连 Git。但 Cloudflare Pages 有两条硬限制，超限的文件会被标红并拒绝上传：

限制项 拖拽上传（后台） Wrangler CLI
单文件大小 25 MiB（两种都一样）
文件数量 1,000 个 20,000 个
我们目录里有 两个文件超限：ffmpeg-core.wasm（30.6 MB）和 OuonnkiTV-2.0.0-win-x64-portable.zip（121 MB）。 直接拖整个文件夹，这两个会上传失败。
  1. 用已经准备好的精简目录
    打开 site-cloudflare 文件夹（已自动排除上面两个大文件，只剩 11 个文件、0.3 MB）， 直接拖进去就能一次成功。
  2. 在后台操作
    Cloudflare 后台 → Workers & Pages → Create → Pages → Upload assets → 填项目名 → 把文件夹拖进虚线框 → Save and Deploy。
    Workers & Pages → Pages
    Create a project
    □ Upload assets拖拽 site-cloudflare 文件夹
    Save and Deploy → 得到 https://项目名.pages.dev
  3. 大文件走 R2 或 Releases
    Windows 包 121 MB 建议传到 GitHub Releases（第一篇教程就是这个流程）。 页面上的下载按钮做了自动判断：本站有这个文件就用本站，没有就自动跳 Releases， 所以精简目录传上去之后按钮不会变死链。
  4. （可选）工具箱的引擎也搬进 R2
    默认会去 unpkg 取 ffmpeg-core.wasm。想加速就在 R2 建公共桶， 把 ffmpeg-core.js 和 ffmpeg-core.wasm 传上去， 然后在 tools.html 里加一行： 
    <script>window.OKI_CORE_CDN = "https://你的R2域名/path/";</script>
拖拽上传每次都是全量替换，改一个文件也得整个重传（0.3 MB 的话无所谓）。 如果以后想只传改动，改用 npx wrangler pages deploy site-cloudflare。

常见问题

为什么包这么小？它们只是 WebView / Electron 壳，界面和内容都由你的实例提供， 所以只有十几 KB（Windows 版因为内置 Chromium 运行时才有 121 MB）。

能改默认地址吗？能。Android 菜单键 → 设置首页地址；Windows 帮助 → 打开配置文件夹改 config.json；也可以直接改源码里的 HOME_URL 重新打包。

播放没声音 / 打不开？确认实例地址能正常访问，且是 https（或已在壳里放行 http）。
