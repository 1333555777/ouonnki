为什么默认是演示数据

OuonnkiTV 是开源的视频聚合前端，只负责检索与播放的实现， 不内置、不托管、不缓存任何影视内容。没配置片源时，页面展示的是演示条目； 一旦你在设置里填入自己的接口，搜索与播放就全部走你的源。

三步接上片源（本页就能做）

  1. 点页面右上角（或 Hero 区）的 「片源设置」，粘贴你的接口地址，例如 https://你的域名，保存。
  2. 回到顶部搜索框输入片名，页面会并发请求你配置的所有源并合并结果。
  3. 若浏览器报跨域（CORS），在设置里填一个代理前缀 （形如 https://你的域名/proxy?url=）即可 —— 怎么搭代理； 自部署 OuonnkiTV 实例时也可用环境变量 OKI_INITIAL_VIDEO_SOURCES 预置。

片源设置

只保存在你自己的浏览器里，不会上传到任何服务器
填接口的根地址即可，例如 https://api.example.com， 页面会自动拼 /api.php/provide/vod/?ac=videolist&wd=关键词； 也可以直接填一个 .json 静态文件的完整地址。 填完点右侧「自检」可以立刻验证它是否返回有效 JSON。
留空则浏览器直连。多数片源不允许跨域访问，填一个代理即可（结尾要带 ?url=）。 不会搭？看 跨域代理搭建指引 （提供 Cloudflare Worker 与本地 Python 两版，复制即用）。
