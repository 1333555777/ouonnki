OuonnkiTV 是开源的视频聚合搜索与播放前端。 它不托管任何内容—— 你配置自己的视频源，它负责把多路检索、海报匹配与播放体验整理干净。 现在提供 TV 电视端、PC 桌面端、手机端 三套客户端。

02 / FEATURES

把搜索、匹配、播放串成一条顺手的路径

功能围绕「找得到、看得清、续得上」三件事展开，没有多余的社交与推荐流。

F · 01

聚合搜索

一次输入，并发请求多个视频源并合并去重，按相关度与可用线路排序， 失效源自动降权。

F · 02

TMDB 智能匹配

接入 TMDB 后自动补全海报、简介、演职员与评分，搜索结果从「一串标题」 变成「一眼可挑」。

F · 03

播放器

ArtPlayer 5 搭配 hls.js，支持 HLS 流、倍速、清晰度切换与进度记忆， 移动端与遥控器均可操作。

F · 04

收藏与历史

收藏夹与观看历史本地留存，换设备时导出一份 JSON 配置即可整体迁移。

F · 05

视频源订阅

支持单行 JSON、多行 JSON 与远程 URL 三种方式导入源，可逐条启停、 排序与校验。

F · 06

响应式与深色模式

从手机竖屏到 4K 电视横屏自适应，跟随系统切换明暗主题，大屏下自动放大焦点元素。

F · 07

访问密码

自部署实例可设置访问密码，适合在小范围内分享，避免被公开扫描与滥用。

F · 08

不存内容

项目只做展示与播放，不托管、不缓存、不分发任何受版权保护的内容， 数据留在你自己的设备上。

03 / SELF-HOST

不想装客户端？也可以自己托管一份

纯前端项目，任何能托管静态站点或容器的地方都能跑起来，几分钟即可上线私有实例。

Docker Compose

docker-compose up -d --build 内置 Nginx 与代理服务，改环境变量后重建容器即生效。

Vercel

Serverless Function 代理 一键导入仓库即可部署，适合零运维。

Cloudflare Pages

functions/proxy.ts Workers Functions 承担代理，全球边缘节点。

Netlify

netlify/functions/proxy.ts 与 Pages 类似的无服务器代理实现。

本地开发

pnpm install && pnpm dev 需要 Node.js ≥ 20 与 pnpm ≥ 9.15.4。
04 / OPEN SOURCE

技术栈

基于 React 19 与 Vite 6 构建，采用 Feature-Sliced 组织方式， 核心检索与解析逻辑抽离为独立的包，便于二次开发。
